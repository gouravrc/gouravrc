### Overview 

Solaris is an AI-powered banking evaluation tool designed to:

🌞 Optimizing Solar Panel Placement: Predicts solar irradiance using machine learning to recommend the most efficient panel installation sites.

💰 Assessing Green Loan Eligibility: Evaluates financial feasibility for residential and commercial solar investments.

🌱 Promoting Sustainability: Encourages the adoption of renewable energy and supports the transition toward a carbon-neutral future.


### 🛠️ Tech Stack

Machine Learning: Python (Linear Regression, Scikit-learn, Pickle)

Frontend: React.js + TypeScript + Axios

Backend: Java 17 + Spring Boot

Cloud Services: Google Cloud Platform, Firebase, Firestore
